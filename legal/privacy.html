Política de Privacidad

Última actualización: 10 de septiembre de 2026

Esta política explica qué información puede procesar CrosAim y para qué se utiliza.

1. Información que puede procesarse

Dependiendo de las funciones que utilices, CrosAim puede procesar datos técnicos y de Discord necesarios para prestar sus servicios, como:

  • ID de usuario de Discord.
  • ID de servidor.
  • ID de canales, roles o mensajes cuando una función concreta lo requiera.
  • Configuraciones del servidor y preferencias relacionadas con el bot.
  • Información necesaria para diagnosticar errores, abusos o solicitudes de soporte.

CrosAim no solicita contraseñas, tokens de Discord ni datos de tarjetas de pago.

2. Cómo utilizamos la información

La información puede utilizarse para proporcionar y mantener las funciones del bot, guardar configuraciones, solucionar problemas, mejorar el servicio, prevenir abusos y mantener la seguridad.

3. Datos de contenido

Algunas funciones pueden necesitar procesar temporalmente contenido de Discord para ejecutar un comando o función solicitada. CrosAim debe configurarse para conservar únicamente los datos que realmente sean necesarios para sus funciones.

4. Compartición de información

No vendemos información personal. La información podrá ser procesada por proveedores técnicos necesarios para operar el servicio, cuando corresponda, o divulgada cuando sea legalmente necesario para cumplir una obligación o proteger la seguridad del servicio.

5. Conservación y eliminación

Conservamos la información durante el tiempo necesario para prestar las funciones correspondientes, mantener la seguridad o cumplir obligaciones legales. Cuando los datos ya no sean necesarios, podrán eliminarse.

6. Seguridad

Aplicamos medidas razonables para proteger la información frente a accesos no autorizados, pérdida, alteración o uso indebido. Ningún servicio conectado a Internet puede garantizar seguridad absoluta.

7. Servicios de terceros

CrosAim funciona dentro de Discord. El uso de Discord también está sujeto a las políticas y condiciones de Discord. Las funciones que utilicen servicios externos pueden estar sujetas a sus propias políticas de privacidad.

8. Solicitudes relacionadas con datos

Si deseas consultar, corregir o solicitar la eliminación de información relacionada con CrosAim, utiliza el canal oficial de soporte del proyecto. La solicitud podrá requerir información suficiente para localizar los datos correspondientes.

9. Cambios en esta política

Esta Política de Privacidad puede actualizarse cuando sea necesario. La versión vigente se publicará en esta página.

10. Contacto

Para preguntas sobre privacidad o tratamiento de datos, utiliza el canal oficial de soporte de CrosAim.
